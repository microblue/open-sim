An RC flight training simulator with a sectioned, per-surface flight model.
Fly with a real transmitter over USB (EdgeTX / OpenTX joystick mode) or the keyboard.

## Download

| System | File |
| --- | --- |
| Windows 10/11 (64-bit) | `OpenRC-Simulator-0.2.0-windows-x86_64.zip` |
| macOS 11+ (Apple silicon and Intel) | `OpenRC-Simulator-0.2.0-macos-universal.zip` |
| Linux (x86_64) | `OpenRC-Simulator-0.2.0-linux-x86_64.tar.gz` |

Unzip and run. No installer, nothing else to install.

- **Windows**: SmartScreen may warn about an unknown publisher. Choose *More info* → *Run anyway*.
- **macOS**: the app is not notarised. The first time, right-click it and choose *Open*.
  If macOS says the app is damaged, run `xattr -dr com.apple.quarantine "/Applications/OpenRC Simulator.app"` once.
- **Linux**: `./opensim`. Needs Vulkan drivers.

## New in 0.2

- **Why it crashed**: after a crash, a card names the cause (stall, tip stall, spin, spiral dive, hard landing, tree...)
  from the last seconds of the flight, with what to do differently. *Tab* replays it.
- **Failure practice**: optionally, one random failure per flight (motor, a servo, radio), only once you are really
  flying. *Shift+R* flies the same failure again. Your record is kept honestly.
- **Ground effect**: the float in the flare, and the low wing lifting in a banked turn near the ground.
- **Settings**: volume, fullscreen, units, Mode 1 / Mode 2 (keyboard follows), failure practice.
- **Flying aids**: low / far / battery warnings, auto-zoom on a distant model, a height mark on the ground,
  pause when the window loses focus.
- **F10** saves the last two minutes of flight as CSV.
