An RC flight training simulator with a sectioned, per-surface flight model.
Fly with a real transmitter over USB (EdgeTX / OpenTX joystick mode) or the keyboard.

## Download

| System | File |
| --- | --- |
| Windows 10/11 (64-bit) | `OpenRC-Simulator-0.3.0-windows-x86_64.zip` |
| macOS 11+ (Apple silicon and Intel) | `OpenRC-Simulator-0.3.0-macos-universal.zip` |
| Linux (x86_64) | `OpenRC-Simulator-0.3.0-linux-x86_64.tar.gz` |

Unzip and run. No installer, nothing else to install.

- **Windows**: SmartScreen may warn about an unknown publisher. Choose *More info* → *Run anyway*.
- **macOS**: the app is not notarised. The first time, right-click it and choose *Open*.
  If macOS says the app is damaged, run `xattr -dr com.apple.quarantine "/Applications/OpenRC Simulator.app"` once.
- **Linux**: `./opensim`. Needs Vulkan drivers.

## New in 0.3: a redesigned interface

- **Fly in one press**: the first launch asks keyboard or transmitter, lets you try the keys, then
  **Start first flight**. After that the menu opens on your last aircraft, place and weather with FLY selected:
  press Enter.
- **Guided first flight**: six steps (take off, climb, set power, turn around, fly back, land) with one hint at a
  time. Crash part-way and you retry from that step, not from the runway.
- **New flight display**: speed, attitude and height together at the bottom, speed marked against this aircraft's
  own stall speed; it changes with the phase of flight. *V* switches Clean / Standard / Detailed.
- **Hints that help and then step back**: how to get back to the field, how to land, press *C* when the model is
  out of view. Once you have done something three times, its hint stops appearing.
- **Crash card buttons**: Fly again (*R*), Try again in the air (*T*), Watch the replay (*Tab*).
- **Transmitter setup**: radios are detected and named; if none shows up, a checklist and the devices the
  computer can see. The check page flags a channel that looks reversed.
- **Main menu**: aircraft, location, weather and start position (runway, in the air, on approach) as cards you
  click to change. Our own logo and splash screen.
- Number keys *4–8* (failure practice) now only work once enabled in Settings → Practice.
- Sharper text everywhere, including at 1280×720.
